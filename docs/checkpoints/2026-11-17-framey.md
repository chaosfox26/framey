# Framey checkpoint — November 17, 2026

Framey's current development source is preserved locally. The optional Decky
separation has implementation and test source in the working tree, but this
checkpoint does not establish that the complete add-on is released, verified on
the headset, or ready for all original plug-ins. Framey development and the broad
116-plug-in acceptance pass remain paused.

## Source snapshot

The November 17 snapshot covers 360 source files on `experimental`, based on
commit `0407eeb8c75b78f30fb6e6f8793847c3953092ba`. The archived files were
verified against their recorded hashes. This checkpoint covers the development
source as it stood on that date.

## Direction to preserve

Native Framey is the primary product. Decky compatibility is a separately
versioned, optional download, off by default for both new installs and upgrades.
Settings should download and verify the add-on when explicitly enabled, and
allow disabling or removing it while retaining imported plug-ins and their
settings. Closing the Store must not stop enabled imported plug-ins. Native
Framey must work with the compatibility payload physically absent.

Keep the accordion launcher, separate tool windows, native plug-in path, and
first-party Fan Control integration. The proposed upscaler and installer options
are separate deliverables; their availability is not established by this
checkpoint. The detailed separation requirements and implementation plan are in
[the design](../superpowers/specs/2026-10-28-optional-decky-runtime-design.md) and
[the plan](../superpowers/plans/2026-10-28-optional-decky-runtime.md).

## What is present in source

- `decky_runtime/` contains the extracted compatibility package. Its metadata
  declares version `0.1.0`, manager/core API 1 and compatibility profile 1.
- `fy_decky_runtime.py` contains the core manager, disabled default, verified
  package download/install handling, enable/disable/removal operations, and
  generation checks that reject stale work. Framey's core and Settings call it.
- `fy-optional.js` provides the frontend connection. `fy-settings.js` contains
  the enable, cancel, refresh and remove controls; catalog access checks whether
  the runtime is enabled.
- `core-files.txt`, `fy_core_layout.py`, and `tools/pack_core.py` define the core
  package boundary. `tools/pack_decky_runtime.py` builds the separate runtime
  archive and release metadata.
- Test source covers the absent-payload native core, native workers and settings,
  package layout, download validation, disabled admission, cancellation,
  lifecycle cleanup and data preservation. Test presence is not a passing run.

The manager points at first-party GitHub release metadata. No
`decky-runtime-release.json` exists at this checkout's root. Upstream publication
was not queried for this checkpoint, so a public download is **not verified**.
Existing documentation still includes older integrated-runtime instructions;
it needs reconciliation with the optional package before release.

## Evidence and limits

The saved [readiness assessment](../decky-status.md) remains **0 of 116 original
plug-ins verified fully usable on Frame**: 18 have partial evidence, 76 were
blocked at their last assessment, and 22 were not yet tested. These are the
recorded assessments, not fresh results for the extracted runtime. Bounded
method tests, settings persistence and import success do not count as complete
plug-in workflows.

The [README's verification table](../../README.md#current-verification) describes
the older October 26 source `0b0b3a3` and SteamOS VR 0.5.6 checks. Those results do
not certify this dirty working tree. Its recorded separate-panel restoration
issue and incomplete physical-controller acceptance remain unresolved here.
The [runtime evidence](../decky-runtime.md) and
[Steam Frame integration notes](../steam-frame-integration.md) likewise retain
their stated narrower test boundaries.

The November 16 core package contained 46 source files and a version marker.
All 46 matched the November 17 working tree byte for byte. The package excluded
the optional Decky payload. The earlier installation report covered development
Framey and Frame Fan 1.0.2 on SteamOS 0.5.9. Verification after a full headset
reboot was still pending.
